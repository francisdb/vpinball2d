# North Pole (Playmatic 1967) - sidecar

This table needs no game logic in the engine: the `.table.json` sidecar is
pure static config (flipper / slingshot / bumper / drain sounds and the
slingshot rubber animations - see vpinball/vpinball#2263). No `.lua`.

Install by copying the sidecar next to the table's `.vpx` (file stem must
match):

```
~/vpinball/tables/North Pole (Playmatic 1967)/
  North Pole (Playmatic 1967) v600.vpx
  North Pole (Playmatic 1967) v600.table.json
```
